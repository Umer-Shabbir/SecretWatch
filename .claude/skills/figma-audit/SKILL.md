---
name: figma-audit
description: Audit SecretWatch Figma screens for design-system compliance, structure, naming, spacing, and overlap.
---

Check:

- normal frames, no Sections
- unique screen names
- `[AREA] / [SCREEN] / [STATE]`
- no overlap
- 120px recommended spacing
- reusable components
- semantic variables
- correct typography
- correct colors
- restrained radius
- border-driven surfaces
- responsive rules
- accessible interaction states
- no raw secrets

This skill is read-only unless the user explicitly asks for Figma corrections.
