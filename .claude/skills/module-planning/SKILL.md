---
name: module-planning
description: Create a small, dependency-aware implementation plan for one SecretWatch module without coding it.
---

Produce:

1. goal
2. dependencies
3. Figma work
4. backend/data work
5. frontend work
6. integration work
7. tests
8. security checks
9. completion criteria
10. files likely affected

Do not expand the module into unrelated work.

Do not implement until the plan is accepted or the orchestrator authorizes implementation.
