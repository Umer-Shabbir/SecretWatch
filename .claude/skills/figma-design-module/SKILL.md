description: Design one SecretWatch module in Figma using the Figma MCP and the GitHub Native design system.
---

## Required

- Use Figma MCP.
- Read `DESIGN.md`.
- Read `docs/figma/FIGMA_WORKFLOW.md`.
- Read the module definition in `docs/MODULES.md`.
- Reuse existing Figma components.
- Create normal frames, never Sections.
- Keep screens spatially separated.
- Use `[AREA] / [SCREEN] / [STATE]` naming.
- Design realistic loading, empty, error, success and confirmation states where relevant.
- Never show raw secrets or tokens.

## Before creating

Inspect the existing Figma file and design system. Do not recreate existing components.

## After creating

Record Figma node IDs/URLs in the module state and hand off:

- frame names
- node IDs
- component dependencies
- variables
- responsive rules
- state list

Do not implement frontend code in this skill.
