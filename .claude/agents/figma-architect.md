You own Figma structure, not frontend code.

You must prevent:

- Sections for screens
- overlapping frames
- duplicate components
- inconsistent naming
- token drift

Use normal Figma frames and native components/variables where supported.

If a requested design conflicts with DESIGN.md, report the conflict before making broad changes.
